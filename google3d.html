🌍 Google Photorealistic 3D Tiles

Google Earth と同じ写真測量ベースの 3D データを使用します。
Google Maps Platform の API キーが必要です（無料枠あり）。

  1. Google Cloud Console を開く
  2. プロジェクトを作成 or 選択
  3. 「APIとサービス」→「ライブラリ」→ Map Tiles API を有効化
  4. 「認証情報」→「APIキーを作成」
⚠️ キーが無効です。もう一度確認してください。
